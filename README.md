# Text Diff
[![Version](https://img.shields.io/badge/Version-26.0126a-ffc8c8)](https://github.com/csmru/text-diff/commits) [![Hosted on GitHub Pages](https://img.shields.io/badge/GitHub-Pages-2b7346?logo=github)](https://csmru.github.io/text-diff/) [![English](https://img.shields.io/badge/Guide-English-blue?style=flat-square&logo=google-translate&logoColor=blue)](README.md) [![한국어](https://img.shields.io/badge/Guide-한국어-white?style=flat-square&logo=google-translate&logoColor=white)](README.ko.md)

> A modern, fast, and secure client-side text comparison tool built with Vanilla JavaScript.</br>Efficiently computes and displays differences between two text inputs with a clean, responsive UI.


## Features

-   **🔒 Private & Fast**: 100% local processing using Web Workers. Your data never leaves your browser.
-   **📂 Drag & Drop**: Support for text file uploads and intuitive drag-and-drop.
-   **🛡️ Secure & Safe**: Strict **Whitelist Validation** ensures only safe text file formats are processed.
-   **🌗 Light & Dark Mode**: Automatic theme detection with manual toggle.
-   **🔍 Smart Navigation**: Jump between changes easily with the D-pad or Arrow keys.
-   **↩️ Ignore Enter (Optional)**: Focus on content changes by optionally ignoring newline differences.
-   **🧹 View Only diff (Optional)**: Filter out unchanged text to focus solely on modifications.

## Keyboard Shortcuts

| Key | Action |
|---|---|
| `➡️` / `D` | Jump to **Next** Change |
| `⬅️` / `A` | Jump to **Previous** Change |
| `⬆️` / `W` | Scroll to Top |
| `⬇️` / `S` | Scroll to Bottom |

> **Note**: Shortcuts are disabled while typing in the input areas.
